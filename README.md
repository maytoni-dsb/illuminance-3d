# Калькулятор освещения

Расчёт освещённости в пустой прямоугольной комнате методом излучательности (gathering с ядром).
Спецификация — живой документ: https://claude.ai/artifact/911Gfh2dzzs71fY7wyDCSB

## Запуск

```
python -m http.server 8000
```

Открыть http://localhost:8000 (через `file://` ES-модули не загрузятся). Three.js 0.170.0 подключается с jsDelivr через import map.

## Тесты

```
npm test
```

Node 18+, без зависимостей (`node:test`). Расчётные модули не используют DOM и Three.js.

## Состояние

Этап 1 — геометрия и 3D-вид: `js/geometry.js`, `js/view3d.js`, `js/ui.js`, `index.html`.
Критерии этапа проверяются тестами (`tests/geometry.test.mjs`) и панелью «Критерии этапа 1» на странице,
которая считает нормали по вершинам построенных треугольников.
