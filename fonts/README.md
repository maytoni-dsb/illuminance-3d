# Report font

The report is set in Suisse Int'l. It is a commercial typeface and is not stored in the repository.

The report looks for it in this order:

1. Installed on the computer (Suisse Intl / Suisse Int'l, weights Regular, Medium, SemiBold).
2. Files in this folder: `SuisseIntl-Regular.woff2`, `SuisseIntl-Medium.woff2`, `SuisseIntl-SemiBold.woff2`.
3. Inter (Google Fonts), then Helvetica Neue / Arial.

Put licensed `.woff2` files here to give every user of the deployed page the same font without installing it.
